# MEGA27-15: Computational design of disease-refractory mosquitoes

**Research angle.** Gene-drive CRISPR constructs can make *Anopheles* mosquitoes
refractory to malaria transmission, but real-world deployment fails through (a) weak
gRNA efficacy at the drive target site and (b) resistance alleles generated by
end-joining repair. This project is a fully computational design study:

1. **Target mining**: scan published, validated drive target genes (starting with
   *doublesex*, AGAP004050 - the Kyrou 2018 Nat Biotechnol target) for all NGG
   target sites, scored by a CNN trained on real CRISPR efficacy data.
2. **Design ranking**: filter by splice-boundary proximity, GC, homopolymers, and
   off-target load inside the scanned locus panel.
3. **Drive-dynamics simulation**: discrete-generation recursion for homing drive
   allele frequency with resistance-allele generation and fitness costs
   (Burt 2003 / Unckless 2017 class models), plus stochastic Wright-Fisher runs.
4. **Discovery attempt**: ranked novel candidate target sites with predicted
   high efficacy + low resistance-generation potential, compared against the
   published validated dsx gRNA as a positive control.

Real data: gene sequences pulled live from NCBI (Anopheles gambiae). CNN efficacy
scorer trained on Doench 2016 (5,310 experimentally measured guides).

**Paper**: `paper/` - 20-page Times New Roman research paper with figures.
